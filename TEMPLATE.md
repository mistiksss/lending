# Шаблон официального лендинга

Одностраничный сайт: тёмная шапка, скролл-фильм, блоки преимуществ.

## Как отдать нейросети

Приложи этот репозиторий и напиши:

> Пересобери шаблон под компанию [название]. Продукт: [модель].  
> Тон — официальный, деловой, без жаргона. Тексты на русском.  
> Меняй только `src/lib/site.ts` и файлы в `public/`. Компоненты не трогай, если не нужна новая сетка.  
> Видео заказчика разложи в `public/sequence/frame-000.webp` … и поставь `film.frameCount`.  
> Статичные кадры — в `public/stills/`. Цвет акцента — `--color-solare` в `src/app/globals.css`.

## Что менять

| Файл | Зачем |
| --- | --- |
| `src/lib/site.ts` | Бренд, тексты, пункты меню, кадры, фото |
| `public/sequence/` | Последовательность для скролл-сцены |
| `public/stills/` | Боковой, задний, интерьер и любые фото блоков |
| `src/app/globals.css` | Акцентный цвет (`--color-solare`) |

Компоненты в `src/components/` читают только `site`. Названия заказчика там нет.
